# 長文の明示変換：追加標本での検証 — 2026-09-09

採用済みの長文向けモデル重みを、従来の400項目と重複しない200項目で検証した。
Spaceの完全一致は66件から74件へ増加し、9件改善・1件悪化だった。
LIVEの変更記録と実行ステータスの分布は全件一致した（正解72件）。
この結果を受けたパラメータ変更は行っていない。

## 比較条件

同じ採用済み評価バイナリとQ3_K_Mモデルで、明示変換の通常重み0.2と、
20文字以上だけ0.4にする採用済み設定を比較した。200項目中148項目が設定の対象だった。
LIVEの設定、辞書、候補探索、終了確率は同じである。

改善には次の例が含まれる。

- 「彼女は自責で卒業した」から「彼女は次席で卒業した」
- 「資金調達のために債権を発行」から「資金調達のために債券を発行」
- 「主神が一旦はゴールを宣した」から「主審が一旦はゴールを宣した」

唯一の完全一致の悪化は「称賛を浴びた」から「賞賛を浴びた」。
表記の違いだが、参照表記との不一致として悪化に数えている。
改善の側にも「と言っても」から「といっても」のような表記差が含まれる。
増加した8件すべてを意味上の誤変換解消とは扱わない。

## 標本と制約

`target/evaluation/jwtd/2.0/discriminative_dev.json` の4,788項目から、
従来の400項目とID、原文、読みのいずれかが一致する項目を除外した。
残る4,757項目を固定文字列とIDのSHA-256で並べ、先頭200項目を採用した。
選択時に変換結果は参照していない。選択後の200項目はID・原文とも相互に重複しない。

これは従来のニューラル評価標本とは異なる項目での追加確認である。
ただし元データは以前の辞書候補評価でも使用済みで、新しい独立コーパスや
モデルの学習外データであることを保証するものではない。他のIMEに対する優位性も証明しない。
