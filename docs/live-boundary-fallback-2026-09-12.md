# LIVE境界再検討の適用可否とフォールバック

採用済み。前の実験で見つかった悪化を修正し、全件評価・QA再生・署名を確認した。国内最高水準を示す比較や物理キー入力の確認は未完了。

## 二つの原因

助詞に見える一文字を含めて範囲を広げると、既存の文全体の修復を妨げることがあった。「王政による指導」の例では最後の一文字を入力した後、元の範囲なら「旺盛」を「王政」に直せたが、広げた範囲の採点成功だけで処理が終わり、修復されなかった。

そこで、変更候補が表示を変えるか、適用時の文字種・辞書分割・短いかな末尾の保護条件を満たすかをワーカーで検査する。適用処理と同じ純粋な判定関数を使い、適用できない候補は元の範囲へ戻して推論する。入力世代・文脈・候補集合の検証は適用時にも維持する。

もう一つは「したとし批判」が「した年批判」になる変化。「としひ」の入力時点でモデル採点とは別の辞書補正が「都市費」を選んでいた。採点ログは同じ候補を別途採点した診断値であり、内部の元の呼び出しを直接記録したものではない。トレースの最終出力がQA再生と一致することは確認した。これは元の範囲の末尾修復を、境界を広げた範囲でも使ったことによる。広げた範囲では辞書だけを根拠とする置換を行わず、必要なら元の範囲へ戻す。
