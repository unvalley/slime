# 学習した短い語からの入力継続 — 2026-09-09

前段のLIVE文脈学習を検証したところ、「食事」の後に `hashigo` を入力すると、
途中で学習済みの「箸」を表示した後、「箸ご」が残る回帰が見つかった。
修正後は「箸」から「はしご」へ読み直す。「走る」「走った」「走ろう」「橋本」への切り替えも確認した。

## 修正

LIVEの表示継続処理で、文脈学習から選ばれた、途中で別の語になり得る短い候補を
そのまま次の読みの固定表示として使わないようにした。
対象は既存の `prefix_fragile` 条件に当てはまり、現在の文脈履歴に一致する候補に限る。
読みがまだ変化していない未確定ローマ字の間は、これまでどおり表示を保持する。

最初にすべての `prefix_fragile` 候補を対象にした試験では、UD testの「親心」が
「おやごころ」へ戻る悪化が1件あったため不採用とした。最終修正は文脈学習に限定した。
