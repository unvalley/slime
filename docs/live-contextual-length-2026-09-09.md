# 文脈のあるLIVE対象の文字数変更（2026-09-09）

文脈のある6文字以上の対象では、十分なモデルスコア差があれば表層文字数の変更を許す。既存2,545件のLIVE正解数は1,574→1,577、改善3件・既存正解の悪化0件。追加200件は全出力が一致し、LIVE108正解、明示変換110正解を維持した。合計2,745件ではLIVE1,682→1,685、明示変換1,686のまま。

## 変更の理由

`いえにはやくかえる`のworker対象は、左文脈`家に`、読み`はやくかえる`だった。Q4は「早く帰る」を辞書1位「早く変える」より高く採点するが、文字数変更を許す従来の最小対象長10文字に届かず、LIVEは「家に早く変える」のままだった。

従来の長文条件に、左文脈が空でなく対象の読みが6文字以上という条件を追加する。文字数変更には既存のスコア差0.5を要求し、安定接頭辞を開き直すrequestにはこの追加条件を使わない。さらにCoreの活用語尾・短い対象・世代一致などの適用検査を通す。候補数、モデル重み、明示変換、前段のcost gateはこの段階では変更しない。
