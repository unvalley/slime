## 実際のリクエスト

「このしょうひんをかいたい」は、対象読み「かいたい」、左文脈「この商品を」の LIVE リクエストになる。

| 対象候補 | 辞書コスト |
| --- | ---: |
| 解体 | 4911 |
| 買いたい | 7026 |
| 懐胎 | 7603 |
| 拐帯 | 9062 |
| 改代 | 9979 |
| かいたい | 2147483647 |

首位とのコスト差は 2115。設定上限は 1000 で、対象 4 文字には長い読みや文脈付き 6 文字以上の緩和条件が適用されない。通常採点も文脈付き首位確認も false となり、モデル採点は実行されていない。以前の別採点の結果を、この worker のモデル選択結果とは扱わない。

「この製品を買いたい」「新しい靴を買いたい」「この犬を飼いたい」も同じ対象候補とコスト差で採点されなかった。最後の例の正解「飼いたい」は実際のリクエスト候補に含まれず、採点前の条件だけでなく候補生成の問題も残る。

対照の「古い建物を解体する」は対象「かいたいする」、左文脈「古い建物を」、コスト差 1074 で採点され、首位は後処理の前後とも「解体する」。「古い建物を解体したい」も差 1037 で採点され、「解体したい」が維持された。
