# 長文の明示変換候補を16件へ拡大（2026-09-09）

20文字以上の明示変換だけ、候補生成とモデルへ渡す候補を10から16件へ広げる。20文字未満とLIVEの候補数は維持する。文脈ルールが空の場合の探索省略、トークン容量に応じた分割を導入した状態で検証した。

既存1,654問では改善2・表記差による悪化1。既存の評価集合とID・読み・原文が重ならない長文200問を結果を見ずに抽出し、88→89正解、改善1・悪化0だった。計1,854問で完全一致1136→1138、改善3・悪化1。改善は「高圧光熱→高圧高熱」「得意な近代の権力→特異な近代の権力」「特殊能力が発言→発現」。悪化は「一旦→いったん」の完全一致上の表記差。全集合でLIVE変更記録・worker statusは一致した。

新しい200問でも他の誤変換は残っており、学習データと独立した未知コーパスを証明したものではない。選択対象3,317問から固定seedのSHA-256順で抽出し、出力による選別はしていない。
