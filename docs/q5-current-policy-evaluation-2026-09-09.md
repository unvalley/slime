## 応答時間

既存の長さ別60例を使い、同一実行ファイルでQ3/Q5を交互に3組実行した。各実行のSpace処理時間の指標を取り、その中央値を示す。ビルドや全件評価とは並行させていない。

| 指標 | Q3 | Q5 |
| --- | ---: | ---: |
| p50 | 24.48 ms | 23.94 ms |
| p95 | 92.95 ms | 92.61 ms |
| 最大値 | 153.31 ms | 167.58 ms |

この範囲ではp50・p95に大きな差はなかった。物理キー入力から描画までの時間ではなく、評価器のSpace処理時間である。モデルファイルはQ3が約52 MiB、Q5が約70 MiB。今回は速度だけを理由に不採用としたわけではなく、精度の回帰と追加集合での結果を踏まえて既定モデルを維持した。
