# 短文の候補不足の診断（2026-09-09）

Mozc回帰例でモデル採点対象に正解がなかった15例を調べた。このうち「一億」「一万」「のるかそるか」は表示候補には存在していたため、一覧からの欠落は12例だった。モデルに渡す候補だけで表示候補の再現率を報告していた箇所を訂正した。

「一億」「一万」はNumber注釈を持ち、モデルの並べ替え対象から保護される。「のるかそるか」は読みをそのまま残す末尾候補で、採点数の上限から外れていた。いずれも候補を移動すれば選択可能であり、一覧に存在しないとは扱わない。

探索幅を変えると候補集合や読みの末尾候補の位置も変わる。ある幅での順位を、別の幅の候補の単純な続きとみなさない。単発の探索時間も保存しているが、速度の改善・悪化を主張する測定には使わない。
