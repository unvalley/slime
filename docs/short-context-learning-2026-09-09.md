# 短い語の文脈学習 — 2026-09-09

後続の[LIVEでの文脈学習](live-context-learning-2026-09-09.md)では、自動変換でもこの学習を参照する経路を修正した。

「はし→箸」のような短い変換先も、直前に確定した語との組み合わせとして学習できるようにした。
変更前は文脈付き履歴にも通常履歴と同じ最小文字数を要求していたため、記録されなかった。

同じ組み合わせを2回確定すると、「食事」の後の「はし」は「箸」、
「道路」の後は「橋」を優先する。通常履歴の最小文字数は維持しているため、
「箸」が文脈に関係なく先頭になる変更ではない。文脈リセット後は通常の候補に戻る。

## 変更範囲

`crates/slime-core/src/user_data.rs` の文脈付き変換候補の記録・検索・保持順で、
短い日本語の変換済み語を許可した。通常履歴と補完候補の条件は変更していない。
2回以上の確定、直前の読みと表記の一致、外部文脈の2文字以上の表記条件は維持した。
空文字、読みと同じ表記、非日本語の読み、最大長を超える入力も引き続き対象外になる。

保存形式・容量上限・原子的な保存処理・外部変更検出は変更していない。
既存のTSV形式を使い、新しいファイル形式や移行処理は追加していない。
